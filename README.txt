HOW TO PUBLISH TO GITHUB PAGES
------------------------------
1. Extract this ZIP archive.
2. Upload all four .html files AND the complete assets/ folder to your
   intended GitHub Pages repository (or its selected publishing folder).
3. Commit and push the changes, then wait for GitHub Pages to publish.
4. Open index.html on your site. The privacy, terms and user-guide links
   work with relative URLs and can be used for your app listing.
5. Do not rename or move assets/ unless you update the HTML references.

No server, database, build process or paid CSS/JavaScript library is needed.
